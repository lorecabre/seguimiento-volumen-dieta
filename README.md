# Seguimiento de volumen y dieta

Aplicación web instalable para registrar peso, calorías, macronutrientes, pasos, alcohol y notas. Incluye resúmenes semanales y mensuales, gráficos, historial de semanas y backup en JSON.

## Uso local

La app necesita servirse por HTTP para habilitar la instalación y el modo offline. Una opción simple es ejecutar npx serve . dentro de esta carpeta y abrir la dirección indicada.

## Publicación

El proyecto es estático y puede publicarse directamente con GitHub Pages desde la rama principal.
